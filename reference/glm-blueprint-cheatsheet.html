The Three-Part GLM & Exponential Family Blueprint

Compressed side-by-side reference uniting all five core GLM families across specification, exponential-family form, variance functions, and link choices.

1. Every GLM Has Three Pieces & Four Connected Scales

1. Random Component

\[Y_i \mid x_i \sim \text{EDF}(\theta_i, \phi, p_i)\]

Fixes valid outcomes \(\mathcal{Y}\), mean \(\mu_i = b'(\theta_i)\), and variance \(\operatorname{Var}(Y_i \mid x_i) = \frac{\phi}{p_i}V(\mu_i)\).

2. Systematic Component (\(p = \dim(\beta)\))

\[ \begin{aligned} \eta_i &= x_i^\top \beta \\ &= \beta_0 + \beta_1 x_{i1} + \dots + \beta_{p-1} x_{i,p-1} \end{aligned} \]

Combines \(p\) parameters (including intercept; \(\text{df}_{\text{resid}} = n - p\)) on \((-\infty, +\infty)\).

3. Link Function & Complete Parameter Chain

\[ \begin{gathered} \beta \xrightarrow{\;X\beta\;} \eta_i \xrightarrow{\;g^{-1}\;} \mu_i = E[Y_i \mid x_i] \xrightarrow{\;(b')^{-1}\;} \theta_i \\[4pt] \Big(\text{Canonical link } g = (b')^{-1} \implies \eta_i = \theta_i\Big) \end{gathered} \]

Golden rule: Transform the expected value \(g(\mu_i) = \eta_i\), never the raw data \(y_i\) (\(g(E[Y_i \mid x_i]) \neq E[g(Y_i)]\)).

3. Two Diagnostic Questions Before Picking a Model

  1. Range check: What values can \(\mu_i = E[Y_i \mid x_i]\) legally take? Pick an invertible link \(g\) mapping that open interval onto \((-\infty, +\infty)\) (which is why Gamma’s log link beats its canonical inverse link when \(\eta_i\) can cross zero!).
  2. Spread check: How does \(\operatorname{Var}(Y_i \mid x_i)\) scale as \(\mu_i\) grows—constant (\(1\)), pinched at \(0\) and \(1\) (\(\mu(1-\mu)\)), linear (\(\mu\)), or quadratic (\(\mu^2\))? Pick the random component accordingly.
